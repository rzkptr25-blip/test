Paket Backend Fullstack & Siap Hosting

Node.js Reverse Proxy (REST + WebSocket) • Penyimpanan Riwayat Server • Docker Ready

Arsitektur Fullstack Otomatis

Aplikasi ini sudah mendukung Auto-Detect Fullstack Proxy. Saat file index.html diletakkan di folder public/ bersama server.js, frontend otomatis mendeteksi endpoint /api/health lalu meneruskan semua request ComfyUI & WebSocket lewat domain hosting Anda (bebas CORS & aman untuk HTTPS).

1. Struktur Folder Proyek

ref2va-fullstack/
├── server.js
├── package.json
├── .env
├── Dockerfile
├── data/               (otomatis dibuat)
│   └── jobs.json       (riwayat video server)
└── public/
    └── index.html      (file aplikasi ini)

2. Jalankan di VPS / Railway / Render

# Install dependensi
npm install

# Salin env & isi COMFYUI_URL
cp .env.example .env

# Jalankan produksi
npm start

# Atau via Docker:
docker build -t ref2va-studio .
docker run -p 3000:3000 -e COMFYUI_URL=https://wolfgg.online ref2va-studio
